# Akvarium 2 – Interaktiv touchskærmsløsning

## Projektbeskrivelse
Dette projekt er en forbedret version af min første akvarie-case, udviklet som en interaktiv touchskærmsløsning til Storcenter Nords akvarieområde. Løsningen er designet til børn omkring 5 år og har fokus på læring gennem leg, visuelle elementer og interaktive aktiviteter.

Projektet indeholder tre aktiviteter:
- Lær om fiskene
- Vendespil
- Verdenskort

I "Lær om fiskene" kan brugeren trykke på fisk og få vist fakta, som samtidig bliver læst op via lyd.  
I vendespillet kan brugeren finde matchende fiskekort.  
I verdenskortet kan brugeren trykke på en fisk og se, hvor i verden den kommer fra.
